# Dhaaga (धागा)

**One Thread, Many Cultures of India.**

Dhaaga is the red thread that weaves together the history, rituals, heritage, cuisine and craft of every Indian state and union territory.

🔗 **Live site:** https://dhaaga-herc.vercel.app/

## Features

- All 28 states and 8 union territories
- Search by place, dish, craft or festival
- Filter by region
- Tap a card for capital, cuisine, craft, festival and heritage
- Works on phones, supports dark mode, no frameworks

## Run it locally

No build step. Open `index.html` in your browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Project files

| File | Purpose |
|------|---------|
| `index.html` | Page structure |
| `style.css` | Styling, including dark mode |
| `script.js` | Search, filters, and the `PLACES` data list |

## Contributing

Each entry lives in the `PLACES` list at the top of `script.js`. Easy ways to help:

- Fix or enrich an entry (more dishes, crafts, festivals)
- Add photos and a short history for each place
- Add a map view or a "thread" timeline

This is a starter guide, so please double-check facts before adding them and cite a source in your pull request.
